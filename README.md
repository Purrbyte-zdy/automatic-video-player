# automatic-video-player
## 自动视频播放器

## 描述
这个项目是一个 自动视频播放器，允许用户在指定日设置指定时间，自动化的播放新闻或纪录片，并提供了一个简洁易用的 Fluent Design 风格界面。

**该项目并未达到可用水平，不建议在生产环境中使用。**

如果你是其他有类似需求的人，想要使用类似的功能，可以参考这个项目，并根据自己的需求进行修改和扩展。  
如有任何问题或建议，欢迎提交 issue 或 pull request，也可以在 Discussion 中讨论。

## 功能
- **自动播放**：用户可以设置特定的星期和时间，播放器会在指定时间自动开始播放视频，并在固定时间结束播放视频。（未完全开发）
- **简洁界面**：采用 Fluent Design 风格，界面简洁美观，易于使用。（未完全开发）
- **新闻播放**：适配 CCTV 新闻30分，更方便的播放新闻节目。（未完全开发）
